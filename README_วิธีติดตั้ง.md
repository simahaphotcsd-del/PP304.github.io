# PP304 COMMAND — ระบบออกคำสั่งเวรสายตรวจ เลขไทย / TH Sarabun PSK (รุ่น 1.3)

ระบบเว็บไซต์สำหรับ PP304 COMMAND ที่เชื่อมต่อกับ Supabase Project เดิม (ไม่เปลี่ยนตารางฐานข้อมูล) ปรับเฉพาะการแสดงตัวอย่างและส่งออก Word ตามไฟล์ต้นฉบับ “02-เวรสายตรวจ 1-15 พ.ย.9(1).docx”

## สิ่งที่แก้
- ใช้แม่แบบ Word ที่คงข้อความข้อแนะนำและตารางตามต้นฉบับ ทั้ง 15 ตาราง
- เลขอารบิกที่แสดงในเนื้อหาของไฟล์ Word เปลี่ยนเป็นเลขไทยทั้งหมด (รวมวันเวลา ปี ยานพาหนะ และหมายเลขชุด)
- ฟอนต์ไฟล์ Word ใช้ TH Sarabun PSK; เนื้อหา/ตาราง 16 pt และหัวข้อหลัก 18 pt ตัวหนา
- หน้าแสดงตัวอย่างบนเว็บไซต์แสดงคำแนะนำการปฏิบัติจากต้นฉบับโดยตรง ไม่ใช้ข้อความย่อ และแสดงตัวเลขเป็นเลขไทย
- ผลัดดึกยังอ้างอิงจากวันที่ปฏิบัติจริงของ Supabase แต่ในคำสั่งมีหัวคอลัมน์ “ของวันรุ่งขึ้น” ตามต้นแบบ
- ไม่ใส่ลายเซ็นภาพจากคำสั่งเดิม

## วิธีติดตั้ง
1. สำรองไฟล์จาก GitHub Repository เดิมก่อน
2. อัปโหลดไฟล์ `index.html`, `config.js` และโฟลเดอร์ `assets`, `templates` แทนไฟล์เดิม โดยคงชื่อ/ตำแหน่งไฟล์ทุกอย่าง
3. Commit changes และรอ GitHub Pages เผยแพร่
4. Ctrl + F5, ล็อกอินระบบ PP304 COMMAND และเข้าเมนู “ออกคำสั่งราชการ”
5. เลือกช่วงวันที่ไม่เกิน 15 วัน ตรวจชื่อและตำแหน่งผู้ลงนาม และกด “ส่งออก Word (.docx)”
6. เปิดไฟล์ Word ในเครื่องที่ติดตั้งฟอนต์ TH Sarabun PSK เพื่อตรวจระยะหน้า/หน้าตัดตารางอีกครั้ง แล้วลงนามจริงก่อนใช้งาน

## ข้อควรระวัง
- **ถ้อยคำ ยศ ชื่อ ตำแหน่ง ข้อปฏิบัติ และชื่อสถานที่คงตามต้นฉบับ** รวมถึงข้อความที่อาจมีการสะกดคลาดเคลื่อน เพื่อไม่แก้สาระราชการโดยพลการ ให้เจ้าหน้าที่ตรวจทานเองก่อนลงนาม
- ตัวอย่างไฟล์ Word สร้างจากข้อมูลทดสอบที่อ้างอิงเวร 1–15 พ.ย. 2569 และไม่ถือเป็นคำสั่งที่ได้รับการลงนาม
- โปรแกรมสร้างเอกสารใช้วันที่ตามเอกสารต้นแบบ และดึงตารางเวรจาก Supabase; ไม่ใช้สูตรคาดเดาเวรที่ขาดหาย
- ไม่ได้ติดตั้งฟอนต์ TH Sarabun PSK ให้ในไฟล์ ZIP ต้องมีฟอนต์ดังกล่าวในเครื่องใช้งานเอง
- ระยะการแบ่งหน้าในเครื่องที่ไม่มีฟอนต์ TH Sarabun PSK อาจต่างไป; เครื่องทดสอบใช้ฟอนต์สำรอง ทำให้ตัวอย่างท้ายเอกสารขยายเป็น 18 หน้าและช่องลงนามท้ายเอกสารอาจเลื่อนไปหน้าใหม่
- **ความปลอดภัย:** หากเผยแพร่เว็บไซต์บน GitHub Pages สาธารณะ ไฟล์แม่แบบใน `templates/` และข้อความที่ฝังในหน้าเว็บสามารถเข้าถึงผ่านอินเทอร์เน็ตได้ แม้ระบบข้อมูล Supabase จะต้องล็อกอิน ควรประเมินข้อจำกัดนี้ก่อนนำข้อมูลปฏิบัติการจริงออกเผยแพร่ และใช้ Private Storage / Backend สำหรับแม่แบบลับเมื่อใช้จริง

## การทดสอบ
- ทดสอบสร้างไฟล์ Word ผ่านหน้าเว็บในเบราว์เซอร์: ผ่าน ไม่มี JavaScript error
- ตรวจ XML ของไฟล์ Word: ไม่เหลือ placeholder, เลขอารบิกในข้อความ Word = 0, ไม่มีภาพลายเซ็นที่ฝังอยู่
- เทียบข้อความคำแนะนำใน Word กับไฟล์ต้นฉบับครบทั้งสายตรวจรถยนต์ จักรยานยนต์ และนิคม 304: ตรงกันหลังเปลี่ยนตัวเลขเป็นเลขไทย
- ตรวจไฟล์ Word มี 15 ตารางและเปิดด้วยโปรแกรมแสดงผลเอกสารได้
- ยังไม่ได้ทดสอบบนเว็บไซต์ GitHub Pages ของผู้ใช้จริง
