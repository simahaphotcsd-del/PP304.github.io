เวอร์ชัน 1.2 — สำหรับระบบ PP304 COMMAND บน GitHub Pages และ Supabase Project เดิม `uirolrshzxlmoglfugjt`

## เปลี่ยนอะไรแล้ว

เมนู **ออกคำสั่งราชการ** ปรับให้สร้างไฟล์ **Word `.docx` จริง** โดยใช้แบบฟอร์มที่ให้มาเป็นต้นแบบ ทั้งตารางเวรและคำแนะนำการปฏิบัติ คงรูปแบบการจัดหน้าใกล้เคียงต้นฉบับ (ต้นฉบับ 15 ตารางหลัก) ได้แก่

1. ตารางปฏิบัติหน้าที่เวรงานป้องกันปราบปราม
2. ตารางการจัดหน้าที่สายตรวจรถยนต์ 20 (รายชื่อชุด, การหมุนเวร, คำแนะนำ)
3. ตารางสายตรวจรถจักรยานยนต์รหัส 121–128 (รายชื่อ, รถ, ผลัด, คำแนะนำ)
4. สายตรวจเขตนิคมอุตสาหกรรม 304 (ชุด, ผลัด, คำแนะนำ)
5. ตารางเวรวิทยุสื่อสาร
6. สายตรวจตำบล 5 พื้นที่
7. สิบเวร / ควบคุมผู้ต้องหาประจำสถานี
8. เจ้าหน้าที่ประชาสัมพันธ์

**หลักการวัน/ผลัด:** Supabase เก็บตารางทุกผลัดตามวันที่ปฏิบัติจริง สำหรับไฟล์ Word จะปรับกลับเป็นรูปแบบต้นฉบับที่มีคอลัมน์ `00.01–08.00 น. ของวันรุ่งขึ้น` โดยดึงเวรผลัดที่ 1 จาก *วันที่ถัดไป* เช่น เมื่อแสดงวันที่ 1 พ.ย. ใต้ช่องผลัดดึกของวันรุ่งขึ้น จะอ่านเวรของวันที่ 2 พ.ย. ไม่ใช่ของวันที่ 1 พ.ย.

**ลายเซ็น:** ไม่มีการนำลายมือชื่อ/รูปภาพลายเซ็นจากคำสั่งเดิมมาใช้ใหม่ ช่องลงนามเปิดไว้สำหรับการตรวจและลงนามจริงภายหลัง

## วิธีติดตั้งบน GitHub Pages

ให้คัดลอกไฟล์เหล่านี้จาก ZIP ไปยังโฟลเดอร์หลักของ Repository โดยคงโครงสร้างโฟลเดอร์ตามนี้:

```text
index.html
config.js
assets/
    jszip.min.js
    LICENSE.markdown
templates/
    official_duty_unsigned_template.docx
```

- แทนที่ `index.html` เดิมด้วยไฟล์ใหม่นี้ และเก็บ `config.js` ในตำแหน่งเดิม
- **ต้องอัปโหลดโฟลเดอร์ `assets` และ `templates` ด้วย** ไม่ใช่เฉพาะ `index.html` กับ `config.js`
- กด Commit changes และรอ GitHub Pages เผยแพร่ จากนั้นกด `Ctrl+F5` เพื่อรีเฟรชเว็บ
- ไม่มีการเปลี่ยนตาราง Supabase ไม่ต้องนำเข้ากำลังพล/เวรซ้ำ และไม่ต้องรัน SQL เพิ่ม
- ผู้ใช้ต้องล็อกอินและได้รับสิทธิ์จากโปรเจกต์ Supabase เดิมก่อนจึงจะอ่านข้อมูลได้

## ขั้นตอนสร้างคำสั่ง

1. ล็อกอิน PP304 COMMAND แล้วไปเมนู **ออกคำสั่งราชการ**
2. เลือก `เริ่มวันที่` และ `ถึงวันที่` — **ไม่เกิน 15 วันต่อครั้ง** เช่น 1–15 หรือ 16–30
3. ตรวจ/เปลี่ยน `ผู้ลงนาม` และ `ตำแหน่ง`
4. กด **แสดงตัวอย่าง** เพื่อตรวจข้อมูล และกด **ส่งออก Word (.docx)**
5. เปิดไฟล์ `.docx` ด้วย Microsoft Word เพื่อตรวจตัวสะกด ชื่อชุด เอกสารอ้างอิง และช่องลายเซ็น จากนั้นลงนามตามขั้นตอนราชการ
6. ปุ่ม **พิมพ์ / บันทึก PDF** ใช้หน้าแสดงตัวอย่าง HTML เพื่อพิมพ์ได้ทันที แต่หากต้องการ PDF ที่จัดหน้าตาม Word ต้นฉบับที่สุด ให้เปิด `.docx` ใน Word แล้วเลือก **Save As PDF**

## ข้อควรระวัง

- ช่องวันที่/ชื่อ/ชุดที่ไม่มีข้อมูลจาก Supabase อาจแสดงเครื่องหมาย `—` เพื่อให้ผู้จัดทำตรวจสอบ ไม่คาดเดาชื่อเวร
- ช่วงวันใดไม่มีตารางเวรเลย ระบบจะไม่สร้างคำสั่งเปล่า
- รูปแบบตารางเวรต้นฉบับที่รวมวันของรอบ 8 วันไว้ในแถวเดียวกันต้องมีรูปแบบรอบเวรตรงกัน มิฉะนั้นระบบจะแจ้งเตือนว่าข้อมูลเกินช่องของแม่แบบ
- หมวดคำแนะนำในการปฏิบัติเป็น **ข้อความที่ถอดแบบตามไฟล์ Word ที่ผู้ใช้ให้มา** ไม่ใช่ข้อสั่งการที่ระบบตรวจสอบหรืออัปเดตอัตโนมัติ จึงต้องตรวจให้ตรงคำสั่งปัจจุบันก่อนลงนาม
- หากใช้แบบฟอร์มในช่วงวันที่ใหม่ ให้จัดเวรและตรวจสอบการลาหรือการแทนเวรให้เรียบร้อยก่อน
- หากฟอนต์ `TH SarabunIT๙` ในไฟล์ต้นฉบับไม่มีในเครื่องที่เปิด Word การจัดหน้าอาจต่างจากต้นฉบับเล็กน้อย
