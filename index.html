จัดชุดสายตรวจ / คู่ตรวจ

กำหนดรายชื่อประจำรหัสในแต่ละห้วง เมื่อรันเวร ระบบจะเลือกชุดที่มี “วันที่เริ่มใช้” ล่าสุดซึ่งไม่เกินวันเข้าเวร

ทะเบียนกำลังพล

เพิ่ม/ลดกำลังพลโดยเก็บประวัติไว้ ไม่ลบชื่อออกจากคำสั่งหรือเวรย้อนหลัง เมื่อมีการลดกำลังพล ระบบจะหยุดแสดงชื่อในรายการแนะนำตั้งแต่วันที่ลดกำลังพล

ผู้บังคับบัญชา / เวรงานป้องกันปราบปราม

ใช้สำหรับตารางหน้าแรกของคำสั่ง สามารถกำหนดรายชื่อระดับสารวัตรขึ้นไปเป็นรอบเวร และตั้งวันที่เริ่มใช้ใหม่ได้เมื่อมีการย้าย/เปลี่ยนกำลังพล

สายตรวจตำบล / ตู้ยาม

แก้ไขรายชื่อผู้ปฏิบัติและผู้สนับสนุนของแต่ละตู้/พื้นที่ โดยกำหนดวันที่เริ่มใช้และลำดับรอบ ระบบจะนำไปสร้างหน้า “เจ้าหน้าที่ตำรวจที่ปฏิบัติหน้าที่สายตรวจตำบล” ใน Word/PDF

ค่าเริ่มต้นผู้ควบคุมและผู้ลงนาม

บันทึกครั้งเดียวเพื่อใช้เป็นค่าเริ่มต้นในหน้าออกคำสั่งราชการ กรณีย้ายหรือเปลี่ยนผู้บังคับบัญชาแก้ที่นี่ได้

สรุปผลการตรวจ

รายงาน อ.7 / อ.8 / อ.9

ใช้ฐานข้อมูลผลตรวจชุดเดียวกับ POLICE 4.0 โดยอัตโนมัติ ไม่ต้องนำเข้าข้อมูลซ้ำ

ยังไม่ได้เลือกวันที่

ระบบนับจาก วันที่ + ผลัด + เขตตรวจ + รหัสสายตรวจ + ลำดับจุดตรวจ ตามรูปแบบระบบ อ.7 อ.8 อ.9 ที่ส่งมา หากข้อมูลเก่าไม่มี “เขตตรวจ/ลำดับจุดตรวจ” ให้กำหนดในทะเบียนจุดตรวจหรือ Import ใหม่เพื่อให้รายงานนับได้ครบ

เลือกวันที่และแบบรายงาน แล้วกด “สร้างรายงาน”
